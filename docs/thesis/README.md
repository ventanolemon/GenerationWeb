# Диплом и статьи: материал и текст

Серия для диплома бакалавра по направлению **системный анализ и
управление** и трёх статей, которые из него вырезаются.

**Методическая основа — курсовая работа «АРКУ»** того же автора: та же
последовательность (контекст → альтернативы → целевая система →
показатели → режимы → сценарии) и те же формы таблиц. Схема сохранена
намеренно: она даёт сквозную трассировку от интереса конкретного
человека до технической характеристики, и защищать работу по ней проще,
чем по свободному изложению.

## Как этим пользоваться

Это **не готовый диплом**, а материал и связный текст, из которого он
собирается: формулировки, таблицы, расчёты и рисунки, за каждым из
которых стоит либо прогон, либо явно названное допущение.

Что надо доделать своими руками:

1. **Обзор литературы.** Классы решений и критерий сравнения готовы
   (глава 1, §1.3 в старой редакции и глава 2); конкретные системы и
   ссылки по ГОСТ подставить свои.
2. **Диаграммы в Capella** (глава 5, §5.12). В тексте они пригодны для
   чтения; для защиты нужны в нотации. Объём оценён по каждому уровню.
3. **Два замера** (глава 1, §1.7): трудоёмкость подготовки варианта и
   частота отказов по форме. Второй выполним прямо сейчас на накопленных
   попытках.
4. **Оформление по требованиям кафедры**: титул, ГОСТ на список
   источников, нумерация рисунков, формул и таблиц.
5. **Введение и заключение** — пишутся последними.

## Три правила, которых стоит держаться при написании

**Результат — утверждение, а не система.** Объём работы (≈120 тыс. строк,
3797 автоматических проверок, пять предметных областей) — обстоятельство,
при котором результат получен.

**Числа называют источник и статус.** «48 неразличимых пар на 830
позициях в 16 словарях — замер» либо «трудоёмкость подготовки варианта —
требует замера, методика в §1.7». Третьего состояния у числа нет.

**Границы называются прямо.** Учебный эффект не измерялся; задания с
графическим ответом не покрываются; два дефекта эксплуатации открыты;
одно проектное решение (§5.8) обосновано с малым запасом, и условие его
пересмотра названо. Работа, умалчивающая о границах, проверяется
читателем на первом же вопросе.
